The bounds check allows one pixel solely for integer layout rounding; model assertions have no tolerance.
This is geometry verification, not a glyph screenshot comparison or frame-performance measurement.

### Instrumentation lifecycle limitation and landscape

The landscape attempt failed before handle resizing because getGlobalVisibleRect returns root-view
coordinates, while system input needs screen coordinates. On moto the landscape Activity window was
inset 70px: sender x632 arrived at window x562. The fixture now adds the root's location on screen,
consistent with the [Android View coordinate contract](https://developer.android.com/reference/android/view/View?authuser=3).
The corrected landscape gesture was **not rerun**, for the lifecycle reason below.

After this attempt the launcher showed its widget error view, while settings and widget IDs remained
identical. Broker correctly refused clean handoff. Reviewing logs also revealed Android's
`Force stopping ... finished inst` / `stop ... due to finished inst` behavior at Instrumentation finish.
No explicit force-stop command was issued, but this system side effect conflicts with the owner's
preservation rule. Further instrumentation use was stopped, and its debug manifest registration was
removed. Historical source remains for evidence, with an explicit do-not-reactivate comment.
The earlier native-input assertions remain evidence of those interactions, not certification of a safe
ongoing test workflow. The relationship between target stopping and the landscape error view was
not isolated, so no production cause or fix is claimed.

A normal provider broadcast from shell was refused. Recovery instead launched the existing debug
ResponsiveAuditActivity for one update, which uses the common updater and restores the stored
design through ordinary Activity completion/destruction. Original-baseline recovery
`dcb26b43146245678c5293a52a4dad88` then ended clean, test exit0, including actual widget geometry.
Rotation, stay-awake and original settings were restored. No more instrumentation was used afterwards.

Local continuation validation: `testDebugUnitTest` completed 620 tests, 619 passed / 1 skipped / no
failures or errors (Windows FileProvider test `providerOnlyServesTheShareDirectory` skipped).
Final unregistered fixture `lintDebug` and `assembleDebug` passed; production source is unchanged.
